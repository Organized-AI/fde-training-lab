# Training Modules

## Module 1 — Workflow Audit
**Slug:** `workflow-audit`

Learn how work actually happens, not how the SOP claims it happens.

Outputs:
- operating map
- exception list
- approval points
- current metrics and pain points

## Module 2 — Agent Systems
**Slug:** `agent-systems`

Build one real-loop agent around a workflow with tool use, traces, and human approval.

Outputs:
- workflow agent
- architecture sketch
- trace sample
- integration map

## Module 3 — Evals and Reliability
**Slug:** `evals-reliability`

Create a golden dataset, define failure modes, and measure whether the system is actually good enough.

Outputs:
- golden dataset
- failure taxonomy
- baseline vs improved eval results

## Module 4 — Deployment and Integrations
**Slug:** `deployment-integration`

Design the rollout path that respects the current stack and de-risks adoption.

Outputs:
- shadow mode plan
- rollback / escalation path
- monitoring checkpoints
- integration boundaries

## Module 5 — Business Value and Trust
**Slug:** `business-value`

Translate the system into language a buyer, manager, or operator can believe.

Outputs:
- ROI framing
- risk framing
- stakeholder-specific pitch points
- adoption objections and answers

## Module 6 — Capstone Packaging
**Slug:** `capstone`

Package one flagship project as explicit FDE proof.

Outputs:
- case study
- architecture one-pager
- audit summary
- eval summary
- deployment plan
- stakeholder pitch
