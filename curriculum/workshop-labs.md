# Workshop Labs

## Lab 1 — Audit a messy workflow
Pick a real workflow with at least:
- 8 steps
- 3 stakeholders
- 5 exceptions
- 1 approval bottleneck

Deliverable:
- completed `templates/workflow-audit-template.md`
- short FDE fit memo: why this is technical-platform + non-technical-buyer work

## Lab 2 — Build one real-loop agent
Choose one narrow slice of the workflow and build a working system around it.

Deliverable:
- runnable agent or automation loop
- reusable primitives inventory
- trace log
- demo notes

## Lab 3 — Create a failure taxonomy
List how the workflow can fail in reality.

Deliverable:
- top 15 unhappy paths
- mitigation for each
- which ones require human escalation

## Lab 4 — Build an eval pack
Use 20 to 50 examples.

Deliverable:
- golden dataset
- pass/fail rubric
- baseline result
- improved result

## Lab 5 — Design a deployment path
Design rollout into a live organization.

Deliverable:
- shadow mode plan
- approval gates
- rollback path
- monitoring plan
- what should remain bespoke vs what should become shared product capability

## Lab 6 — Write the business case
Frame the system as a stakeholder-safe investment.

Deliverable:
- cost savings estimate
- risk reduction estimate
- revenue or throughput upside estimate

## Lab 7 — Package the capstone
Turn all prior work into a single portfolio asset.

Deliverable:
- 1-page overview
- architecture summary
- audit summary
- eval summary
- stakeholder pitch
- why this should be recognized as FDE work instead of a custom dev engagement
