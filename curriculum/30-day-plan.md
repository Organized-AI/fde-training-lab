# 30-Day FDE Plan

## Week 1 — Build one real-loop system
Focus:
- choose one real workflow
- map the steps
- build one working agent/system
- include traces and approval points

Definition of done:
- a non-trivial task completes repeatedly
- you can show what happened step by step

## Week 2 — Harden for reality
Focus:
- add structure to inputs and outputs
- handle unhappy paths
- log failures and recoveries
- stop building only for the happy path

Definition of done:
- you know how the system fails
- you have explicit mitigation or routing for major exceptions

## Week 3 — Measure value
Focus:
- build a golden dataset
- run evals
- estimate economics
- improve cost, accuracy, and reliability

Definition of done:
- you can defend the system with evidence
- you can speak about revenue, risk, or cost impact

## Week 4 — Package and pitch
Focus:
- create a case study
- write the rollout plan
- rehearse the pitch as both engineer and operator
- get feedback from real people

Definition of done:
- you have one project that looks like genuine FDE proof
- you can explain problem, solution, risk, and ROI clearly

## Daily cadence
- 45m study / review
- 90m build
- 30m documentation
- 15m scorecard + reflection

## Daily checklist
- What did I audit?
- What did I build?
- What failed?
- What did I measure?
- How would I explain this to a stakeholder?
